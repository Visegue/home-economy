# Säkerhetsbrister

Rapportera brister i Hemekonomi privat via [GitHubs säkerhetsformulär](https://github.com/Visegue/home-economy/security/advisories/new). Lägg aldrig angreppsdetaljer, hemligheter eller verkliga hushålls-/ekonomidata i publika issues eller PR:er.

Ange version eller URL, steg för att återskapa felet, förväntat och faktiskt beteende samt möjlig påverkan. Använd syntetiska exempel. Vi utreder och samordnar rättning och publicering i säkerhetsärendet.

Vanliga buggar och förslag hör hemma i GitHub Issues.
