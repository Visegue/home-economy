# Security policy

If you find a security vulnerability in Home Economy, please report it privately
through [GitHub's vulnerability reporting form](https://github.com/Visegue/home-economy/security/advisories/new).
Do not open a public issue or pull request with exploit details, credentials, or
real household/financial data.

Please include the affected version or URL, reproduction steps, expected and
observed behavior, and the potential impact. Use synthetic data in examples.
We will investigate and coordinate a fix and disclosure through the advisory.

For non-sensitive bugs and feature requests, use regular GitHub issues.
